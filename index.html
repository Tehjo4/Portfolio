Washing Machine Controller Prototype

STM32, STM32CubdeIDE, LEDs

Engineered a prototype of washing machine controller on an STM32 board.

The system used a hardware timer to dictate the duration of each operational state (e.g., wash, rinse, spin), while a MOD-8 counter managed the sequence.

An external interrupt provided pause/resume functionality, and three LEDs served as a status panel, displaying the current cycle in binary.
